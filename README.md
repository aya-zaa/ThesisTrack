# ThesisTrack

A web application for managing student theses and supervisor interactions.

## Description

ThesisTrack is a web-based platform designed to facilitate the supervision process for graduation projects.

It allows students and supervisors to manage tasks, share files, communicate, and track project progress in an organized and simple way.

The system helps improve collaboration and ensures that all project-related information is stored in one place.

## Features

- Task management  
- File upload and review  
- Messaging system  
- Notifications  
- Supervisor-student interaction  

## Technologies Used

- Front-end: HTML, CSS, JavaScript  
- Back-end: PHP  
- Database: MySQL  

## Setup and Execution

1. Install XAMPP or any local server.  
2. Place the project folder inside the `htdocs` directory.  
3. Start Apache and MySQL.  
4. Import the database using phpMyAdmin.  
5. Open the project in your browser using:  
   `http://localhost/thesis_project`
