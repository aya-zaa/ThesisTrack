# 🚀 ThesisTrack  
### *A smarter way to manage academic projects*

---

## ✨ Overview

ThesisTrack is not just a website…  
it’s a complete system designed to organize the entire project workflow — from idea to completion.

Instead of scattered tools and chaos, everything is brought together into one clean, structured experience.

---

## 💡 Concept

ThesisTrack is a web application that connects students and supervisors in a unified environment.

It transforms how projects are managed by making everything:
- centralized  
- organized  
- easy to follow  

No more confusion. No more lost files. No more messy communication.

---

## ⚙️ Core Features

- 📁 **Project Management**  
  Create, track, and manage projects with clear statuses  

- 👥 **Student–Supervisor Connection**  
  Link students with their supervisors in one place  

- 📨 **Built-in Messaging System**  
  Direct communication without external tools  

- 📄 **File Management System**  
  Upload, review, and track files (sent / reviewed / approved)  

- 📝 **Task Management**  
  Assign tasks, set deadlines, and monitor progress  

- 📊 **Dashboard Overview**  
  A clear and real-time view of everything happening  

---

## 🧠 How It Works

The system is structured to keep everything connected:

- Each project includes students, tasks, and files  
- Every action (messages, uploads, updates) is tied to a user  
- Data flows in a way that keeps the experience smooth and intuitive  

Example:
- File status updates dynamically after review  
- Messages are organized into inbox and sent views  
- Projects move through clear stages (in progress → reviewed → completed)
